# 输入清单：哪些要你提供，哪些是模板固定的

做一份案例前，对照这张表把材料收齐。分三类：**必须提供**（没有就做不出来）、**按情况提供**（有就更好/某些情况下必须）、**模板固定**（不用提供，也不要改）。

## 一、必须提供

| 项目 | 形式 | 说明 |
|---|---|---|
| 品类名称 | 一句话，如“家居安防类”“儿童玩具与 DIY 类” | 用于第 1 页标题“××品牌在 Levanta 的联盟营销效果”、第 2 页眉题、文件名。建议以“类”结尾，避免“产品品牌”连读 |
| 三个品牌的后台截图 | 每品牌 2 张 PNG：**效果报告**（含日期范围、站点筛选、Sales / Conversions / Commission / BRB / ROAS 卡片）和**创作者报告**（按创作者的销售额柱状图） | 从 Levanta 后台“效果报告”“创作者报告”直接截全屏；三个品牌尽量用同一日期范围（通常近三个月）。品牌默认匿名为 A/B/C |
| 主要产品名 | 每品牌中文 + 英文，或三品牌统一一个 | 如“儿童玩具与 DIY 产品 / Kids' Toys & DIY Products”。只给中文时由 AI 补一个短英文译法并在备注说明 |
| BRB 的情况 | 三选一：① 效果报告里有 BRB 卡片（直接读）② 后台不显示（筛选含 Creator Connections）→ **你补一个数** ③ 品牌是 VC（Vendor Central）店铺 → 说明“不适用” | 缺 BRB 不能按 10% 估算，也不能当 0。补的数会按后台 ROAS 反推核对 |
| 联系页信息 | `contact.json`：姓名行、中英文职称、邮箱、二维码图片 | **必须是发送人自己的**。二维码用企业微信/微信原图，不裁边不重绘。没有这四项脚本会停下来 |

## 二、按情况提供

| 项目 | 什么时候需要 | 说明 |
|---|---|---|
| 本品类的媒体截图（第 4–5 页换图） | 想让推广示例贴近该品类时；不给则沿用模板的跨类目示例。**先查 `assets/media-library/` 有没有现成的品类包**（目前有家居安防类、儿童玩具与DIY类、厨具类） | 7 类各一张最好：垂类/生活媒体测评、榜单或礼物指南、创作者（Instagram / TikTok / YouTube）、Deal 社区帖、综合媒体导购、Newsletter 邮件、Media Buyer（搜索广告 + 落地页两张）。AI 会逐张识别站名；看不出站名时告诉 AI |
| 策略页的品类词与媒体举例 | 默认加策略页；通用框架固定，每个品类只改“子说明”“适合做的内容”里的品类词和“媒体举例” | 媒体举例只能用创作者报告里有成交的、或你给了截图的主体，不能编 |
| 钩子页问句微调 | 面向特定客户时 | 默认六问通用；可以按多数卖家共性痛点改 1–2 条，不写客户原话、不写竞品名 |
| 目标客户名 | 做“定向版”时 | 出现在第 1、6、7 页眉题（“为 ×× 准备 · …”）和文件名；其余页面不出现 |
| 多站点/独立站说明 | 某品牌截图筛选含 Shopify、DE/UK 等时 | 要么重新导出只含美国站，要么确认保留并在第 1 页标注“B：美国站＋独立站＋英德站” |
| 客户现状、痛点 | 有就能让结论和钩子页更贴近 | 不详也能做：结论改为强调“同类品牌站外出单媒体多元” |
| 页数要求 | 不想要策略页/钩子页时 | 默认八页；“七页”去策略页，“六页”再去钩子页，“两页”只要数据和截图 |

## 三、模板固定（不用提供，不要改）

| 页 | 固定内容 | 可以改的部分 |
|---|---|---|
| 第 1 页 | 表格 11 行结构、指标名、结论区版式、注脚口径（类 ACOS 定义、BRB 政策表述） | 数据、结论三条、页脚、眉题（定向版） |
| 第 2 页 | 三列版式、图片槽位、“上：效果报告 下：创作者报告”、**截图默认打码**（KPI 数值、创作者名称、金额） | 六张图、产品标签、统计期、页脚 |
| 第 3 页 | 成本测算模型与三档 $10,000 / $30,000 / $100,000、费率假设（佣金 15%、平台费 3.5%、月费 $600、BRB 10%）、结论“值得优先布局的高投入产出渠道之一” | 只有用户明确要求改档位/费率时才用 `cost_tiers` 重算；客户月销等信息只作参考，**不写进页面** |
| 第 4–5 页 | 版式、栏位类型（内容型 3 栏 / 促销引流型 4 栏）、深绿总结栏；默认图为跨类目示例 | 给了品类截图时整体换图、换站名、换栏标题 |
| 第 6 页策略页 | 五类框架（内容媒体与垂类媒体 / 榜单与导购 / 红人创作者 / Deal 与 Coupon / Media Buyer）、四列结构、“主要作用”一列、底部 Levanta 定位句（不写演示 CTA） | 品类子说明、适合做的内容里的品类词、媒体举例 |
| 第 7 页钩子页 | 版式、“只列问题不写答案”、底部色带（共同根源 → Levanta 官方定位 → 四个支点 → 演示 CTA） | 六条问句、眉题 |
| 第 8 页联系页 | 标题、场景行、邀请文案、Levanta Logo | 姓名、职称、邮箱、二维码（必须换成发送人自己的） |
| 全局 | 配色、字体、1280×720 版式、页码格式 `0N / 0T`、文件命名 | — |

## 给 AI 的提醒

- 截图里的数字要**逐张打开重读**，不能靠文件名或别人给的汇总；算出来的 ROAS 要和后台卡片一致。
- 页面上是否点名具体媒体/创作者先确认负责人口径；未确认时只写类型。可以点名时也只点**本次截图里有成交且身份明确**的主体，不写单个伙伴的金额。
- 页面不写竞品名称、不承诺结果、不把示例截图说成案例品牌的实绩。
- 交付文件 ≠ 已发客户：不要自动发消息。
