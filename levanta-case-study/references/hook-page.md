# 固定模块：卖家常见问题“钩子页”（可配置）

默认插在**联系与演示邀请页之前**（八页结构下为第 7 页，联系页第 8 页）。目的只有一个：让客户在看完案例证据后对号入座，翻到下一页扫码约 30 分钟演示。**只列问题，不写答案**——答案留给演示。用户只要案例两页、只要推广示例，或明确说“六页”时不加本页。

## 生成方式

```bash
python3 scripts/add_questions_page.py <上一步.pptx> <输出.pptx> <case>/questions.json   # make_case.py 自动调用
```

脚本用 python-pptx 在联系页前新增一页（沿用联系页的 slideLayout，背景 `#F5F8F6`），并把全部页码重编为 `0N / 0T`。默认配置在 `assets/hook-page-default.json`；复制到 case 目录为 `questions.json` 再改，不改默认文件。

## 默认内容（通用版，面向不同站外基础的卖家）

六类问题合并自沙龙 PPT“这些困惑，往往不是单一工具能够解决的”（流量与成本 / 方法与策略 / 资源与筛选 / 效果与衡量 / 人力与执行）与真实客户反馈（仅 Deal 出单、促销邮件失效、清库存不增利）：

1. **流量与成本**｜站内广告越来越贵，想做站外，又担心投入没有效果、成本算不清？
2. **方法与策略**｜知道要做站外，但新品推广、爆品放量、大促、清库存分别该怎么做？
3. **资源与建联**｜想合作内容媒体、测评站和 KOL，不知道该选谁、怎么联系、怎么谈佣金？
4. **出单结构**｜只有做 Deal、给大折扣时才出单，不促销就没流量，利润越做越薄？
5. **效果与归因**｜做过红人、Deal 或 Creator Connections，却说不清哪家真正带来订单、ROI 多少？
6. **人力与执行**｜没有专职站外团队，邀约、寄样、佣金、结算全靠人工，担心增加大量额外工作？

色带文案：

- 共同根源：“这些问题的共同根源：缺少一套围绕消费者旅程、持续经营站外触点、并且算得清账的方法。”（沙龙 PPT 原句 + “算得清账”）
- 定位：“Levanta｜一站式管理全渠道与全球创作者，打造高回报的站外增长体系”
- 支点：“9W+ 高转化资源连接（内容媒体 / 创作者 / Publisher）· 官方归因 API · 开箱即用平台 · 本土策略支持”
- 定位与支点引自《Levanta China_2026.pdf》第 5–6 页（Levanta 官方介绍材料），更新官方材料时同步替换，不自行改写口号。

## 文案边界

- 问题要**通用**：同一页要能让没做过站外的、做过红人/ACC 的、从 Deal 平台转过来的卖家都找到一条。可以为具体客户把其中一条措辞贴近其痛点，但不写客户原话、不写公司名。
- 不写答案、不写承诺、不写竞品名称（PartnerBoost 等一律不出现在页面上）。
- 不把本页写成平台介绍：定位只占色带三行，不展开功能、套餐、报价。
- 本页不替代第 1 页结论，也不改变第 3–5 页固定模块和联系页内容。

## 检查

- 页数与页码：六页案例加本页后共 7 页，所有页码 `0N / 07`（脚本自动重编，渲染后逐页目视确认）。
- `validate.py --original reference.pptx` 通过；本页在 LibreOffice 渲染下每行问句单行、色带内三行文字不重叠、右侧 CTA 不与支点行相撞。
- 演讲者备注写明：问题来源、共同根源出处、定位出处、本次是否为客户定制过某一条。
