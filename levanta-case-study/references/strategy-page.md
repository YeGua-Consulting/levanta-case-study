# 可配置模块：站外媒体组合“策略页”

默认插在第 5 页（推广形式示例第二页）之后、钩子页之前（八页结构下为第 6 页；钩子页第 7、联系页第 8）。目的：告诉客户同类品牌正在组合使用多类站外媒体、Levanta 能一站接入这些类型——**说的是“组合”与“类型”，不是对案例品牌实际投放的总结**。用户只要案例两页、六页、七页时不加。

## 生成方式

```bash
# 在六页案例（含第 4–5 页换图）之后、加钩子页之前：
# make_case.py 自动调用；单独运行：
python3 scripts/add_strategy_page.py <六页.pptx> <输出.pptx> <case>/strategy.json      # 默认插在第 5 页后
python3 scripts/add_questions_page.py <上一步.pptx> <输出.pptx> <case>/questions.json  # 钩子页，页码自动重编
```

脚本用 python-pptx 新增一页（沿用联系页 slideLayout，背景 `#F5F8F6`），所有文字来自 JSON，并把全部页码重编。通用模板在 `assets/strategy-page-default.json`，**复制到 case 目录为 `strategy.json` 再改**，不改默认文件。`insert_after` 可改插入位置（默认 5）。

## 版式（1280×720）

| 对象 | 位置 | 样式 |
|---|---|---|
| 眉题 / 标题 / 副标题 | y36 / y64 / y120 | 与钩子页一致（11pt 绿 / 26pt 粗 / 11pt 灰） |
| 表头 | y160 h34 | 深绿 `#0C2B1C` 白字 11pt 粗，四列：媒体类型 / 适合做的内容 / 主要作用 / 媒体举例 |
| 五行 | 行高 76（`row_height`） | 第一列浅绿 `#E8F4ED`，类型 11.5pt 粗 + 子说明 9pt 灰；其余三列 10.5pt `#2E3B34`，行间 0.75pt 分隔线 |
| 列宽 | `col_widths` 默认 230 / 290 / 270 / 384.4（合计 1174.4） | 媒体举例列最宽，避免英文名在词中间折行 |
| 底部色带 | 表格下方 16px，高 46 | 深绿底白字 12pt 粗，**只写 Levanta 定位一句** |
| 页脚 / 页码 | y690 | 7.5pt / 8pt 灰 |

每格文字控制在两行以内（LibreOffice 回退字体偏宽，渲染后逐行检查）；媒体举例超过 4 个主体时拆成两行写或减少。英文名在词中间折行（“Shop / TODAY”）时，把该格写成数组 `["Shop TODAY、BestReviews、", "The Knot（婚礼清单）"]`，每个元素独占一行；调整顺序让断点落在“、”或“；”后。

## 五类固定框架（按 Levanta 伙伴类型）

1. **内容媒体与垂类媒体** — 子说明按品类写（如“家居生活、亲子、DIY／手工／创客类媒体”）
2. **榜单与导购** — 购物导购 / 礼物指南 / 对比榜单（Newsletter 可并入此行或下一行）
3. **红人创作者** — 子说明写本品类相关创作者类型，举例标平台（Instagram / TikTok / YouTube）
4. **Deal 与 Coupon** — 折扣社区 / 优惠码站 / 比价与返利工具（Cashback 并入）
5. **Media Buyer** — 付费引流：搜索/展示广告 → 榜单或测评落地页

每个案例只改：标题里的品类、各行“子说明”“适合做的内容”里的品类词、以及**媒体举例**。“主要作用”列是通用销售表述，可整套沿用。

## 文案边界

- 媒体举例只写两类来源：本案例三个品牌创作者报告里**有成交**的主体，或用户提供的**公开截图**里可见的站名/账号名；不编造、不写未核实的主体类型。页脚注明来源与“不代表合作承诺”。
- 不把本页写成案例品牌的实际投放复盘；副标题固定“同类品牌已在组合使用；具体合作媒体以双方匹配为准”。
- **底部色带不写演示 CTA**（钩子页色带与联系页已各有一次），只写“以上类型均可通过 Levanta 一站接入：按成交计佣、Amazon 官方 API 归因，同一后台管理全部伙伴”。
- 不写竞品名称、不写套餐与报价。

## 检查

- 页数与页码：八页结构全部 `0N / 08`；`validate.py --original reference.pptx` 通过。
- 渲染后：五行无溢出、英文媒体名不在词中折行、色带单行。
- 演讲者备注写明：五类来源、每个媒体举例的依据（成交金额或截图文件名）、本次相对模板改了哪几格。

## 同一渲染器的其他表格页（overview.json）

`add_strategy_page.py` 只认 `columns`（4 列表头）与 `rows`（type / type_sub / content / role / examples），所以换一组表头就能画别的四列表，`make_case.py` 会自动加载 case 目录里的 `overview.json`（可用 `--no-overview` 跳过）。现成的例子是“多品类案例速览”（`assets/overview-page.example.json`）：列为“品类（样本）/ 规模与佣金 / 渠道效果（BRB 抵扣后）/ 主要出单伙伴”，六行用 `row_height` 60。单元格写成数组可强制换行。
