## 固定上屏文案（模板 v2 默认）

眉题：**推广成本与效果 · 月度测算示例**

标题：**推广成本与效果测算**

副标题：假设：创作者佣金15%＋平台费3.5%＋单品牌优惠月费$600，BRB按10%抵扣｜美元

| 测算项目 | 起步情景 | 成长情景 | 规模情景 |
|---|---:|---:|---:|
| 月归因销售额（假设） | $10,000 | $30,000 | $100,000 |
| 创作者佣金（15%） | $1,500 | $4,500 | $15,000 |
| 平台费（3.5%） | $350 | $1,050 | $3,500 |
| 月平台费（单品牌优惠） | $600 | $600 | $600 |
| BRB 费用抵扣（10%） | −$1,000 | −$3,000 | −$10,000 |
| 净推广成本 | $1,450 | $3,150 | $9,100 |
| 净推广成本率（类 ACOS） | 14.50% | 10.50% | 9.10% |
| 投入产出比（销售额÷净推广成本） | 6.90× | 9.52× | 10.99× |

“月平台费（单品牌优惠）”为用户明确要求保留的行名。金额取整显示，比例与倍数保留两位小数；先用原始精度计算，再格式化。

深绿区主结论：

**按成交计佣，叠加 BRB 抵扣，站外联盟是亚马逊卖家值得优先布局的高投入产出渠道之一。**

- **投入产出**：在上述测算下，每投入 $1 净推广成本，对应约 $6.90–$10.99 归因销售额。
  净推广成本率约为 9.1%–14.5%，可与现有渠道的同口径成本作对照。
- **成本计算**：扣除 BRB 后，净推广成本＝归因销售额 × 8.5%＋$600/月。
- **规模效应**：销售规模扩大，固定月费占比逐步降低；月归因销售达 $100,000 时，净推广成本率为 9.1%，逐步趋近 8.5%。

可见注脚：

本页为成本测算示例，沿用原方案假设，非品牌 A/B/C 实际费用或销售预测。已计平台费和月费，与第1页渠道ROAS口径不同。

BRB按符合条件的美国站品牌卖家10%测算，抵扣后续Amazon销售佣金，以实际核算为准。样品、物流及固定内容费另计。
净推广成本率＝净推广成本÷归因销售额；销售/净推广成本为同口径倍数。月费与平台费按原方案单品牌优惠测算。

品牌数或标签变化时，把注脚的“A/B/C”替换为对应标签或“前述品牌”，不沿用错误品牌映射。单独使用本页时将第1页对比说明改成适合独立文件的说明。

## 为什么是 1 / 3 / 10 万三档

- 原方案的 $10k / $20k / $40k 只覆盖起步段，三档的成本率差异小（14.5%→10%），对月销几十万美元的成熟品牌没有参照点。
- 已做案例品牌的近三个月归因销售额折算到月，从每月几千美元到二十多万美元（汽配 C 约 $235k/月）不等；$10k / $30k / $100k 为近似等比（×3、×3.3）三档，起步、成长、规模各占一档，大多数目标卖家能在其中找到自己。
- 曲线在 $60k 以后趋平（成本率已接近 8.5% 的变动费率），$100k 足以体现规模效应，再往上（如 $200k）多数卖家达不到，用户 2026-11-03 明确不要。
- 档位标签固定为“起步情景 / 成长情景 / 规模情景”；成本率、倍数、结论范围随档位联动，不手改。

## 模型与联动修改

令月归因销售额为S，创作者佣金率c，平台费率p，BRB测算比例b，月平台费F：

- 净推广成本 C = S × (c + p − b) + F
- 净推广成本率 = C ÷ S
- 投入产出比 = S ÷ C

默认c=0.15、p=0.035、b=0.10、F=600，因此C=S×0.085+600。S=100000时C=9100，成本率9.1%。8.5%是佣金及平台费扣除BRB后的销售比例，不含固定月费；对客优先用公式解释，不单独写“变动费用”让卖家猜含义。

用户提供新佣金、优惠、平台费、销售情景或BRB条件时，同步更新副标题、全表、结论中的范围/倍数、规模示例、注脚与备注。若不适用BRB，移除抵扣并重算，不保留“叠加BRB”的主张。零分母或非正成本不显示无限/负回报倍数。

## 可配置模块：`scripts/cost_page.py`

本页的表格、三条结论与演讲者备注由脚本从配置生成，模板 v2 本身已是默认配置的结果，**默认情况下不需要运行**。只有用户要改档位或费率时才用：

```bash
# 独立运行：在六页/七页 pptx 上重写第 3 页
python3 scripts/cost_page.py <in.pptx> <out.pptx> [tiers.json]

# build.py 已自动调用：case-config.json 里有 cost_tiers 字段才会重算，否则保持模板默认 1/3/10 万
```

`tiers.json` / `case-config.json` 的 `cost_tiers` 字段（缺省项取默认）：

```json
{
  "tiers": [10000, 30000, 100000],
  "tier_labels": ["起步情景", "成长情景", "规模情景"],
  "commission_rate": "0.15",
  "platform_rate": "0.035",
  "brb_rate": "0.10",
  "monthly_fee": "600"
}
```

脚本只改第 3 页：表头三个档位标签、第 1–8 行 × 三列数值、`案例结论正文 出单伙伴`（投入产出范围两行）、`案例结论正文 佣金与 BRB`（公式）、`案例结论正文 渠道效果`（规模效应一句，用最高档）和备注；不改副标题（副标题只写费率，费率变了要手改副标题与可见注脚中的“10%”“$600”）。改费率时同时核对副标题、注脚和备注三处一致。跑完脚本后仍要渲染第 3 页目视：三列数值不换行、结论三条各不超过两行。

## 与案例事实及其他渠道的区分

- 本页默认10%BRB为月度模型假设；不能据此补造第1页品牌的实际BRB。第1页缺值仍按data-and-copy.md处理；用户授权估算时明确标识。案例里 BRB 占销售额的比例因类目差异很大（已做案例约 1%–14%），备注里要写明本页按 10% 为假设。
- 第1页渠道ROAS与类ACOS只使用Commission−BRB；本页额外计平台费与月费，不能把两者当同一口径横比。
- “投入产出比”是归因销售额÷净推广成本，不是净利润ROI，也不是因果增量证明。销售额情景不是销量承诺。
- 保留用户确认的“值得优先布局的高投入产出渠道之一”。不自动升级为“投入产出最高的渠道之一”或普遍高于所有站内/站外广告；跨渠道排名需要同期、同归因、同成本范围证据。厂商研究中的ROAS增长幅度不能当作ROAS绝对值排名。
- 当新任务涉及政策资格或新报价时，核对当期官方规则和用户给定商业条款。模板假设不替代客户合同。原BRB政策入口：[Amazon Brand Referral Bonus](https://sell.amazon.com/blog/brand-referral-bonus)。
